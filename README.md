# DriveFleet Client

Live Site: https://drivefleet-client-nu.vercel.app/

## Project Overview

DriveFleet is a modern car rental platform where users can browse cars, add their own cars, book vehicles, and manage rental activities with secure Firebase authentication.

## Features

- User authentication with Email/Password and Google Login
- Browse available rental cars with search and filter functionality
- Add new cars with detailed information and images
- Booking system for reserving rental cars
- User dashboard for managing added cars and bookings
- Responsive design optimized for mobile, tablet, and desktop devices
- Secure Firebase Authentication integration
- REST API integration with Express.js and MongoDB backend

## Technologies Used

- React
- React Router
- Firebase Authentication
- Tailwind CSS
- DaisyUI
- Axios
- React Hot Toast
- Vercel Deployment
